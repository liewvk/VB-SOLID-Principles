# VB-SOLID-Principles

Visual Basic Programming Chapter 1 Subsection 1.1

This repository contains examples and implementations of SOLID principles in Visual Basic .NET.

## Overview

SOLID is an acronym for five design principles intended to make software designs more understandable, flexible, and maintainable.

- **S** - Single Responsibility Principle
- **O** - Open/Closed Principle
- **L** - Liskov Substitution Principle
- **I** - Interface Segregation Principle
- **D** - Dependency Inversion Principle

## Getting Started

This project is written in Visual Basic .NET. To run the examples, you'll need:

- .NET Framework or .NET Core/5+
- Visual Studio or Visual Studio Code with Visual Basic support

## Contents

This repository demonstrates the application of SOLID principles in Visual Basic programming.
